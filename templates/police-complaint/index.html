🚔 காவல் நிலையத்திற்கு எழுத்துப்பூர்வ புகார்Written complaint to a police station

ஒரு குற்றத்தை எழுத்தில் தெரிவித்து, FIR பதிவு செய்ய.To report an offence in writing and to get an FIR registered.

👣 எப்போது பயன்படுத்துவதுWhen to use it

  • திருட்டு, மோசடி, தாக்குதல் அல்லது மிரட்டல் நடந்துள்ளது.A theft, cheating, assault or threat has happened.
  • வாய்மொழியாகக் கேட்டால் காவல்துறை FIR பதிவு செய்ய மறுக்கிறது.The police are refusing to register an FIR orally.
  • எழுத்துப்பூர்வ பதிவும் FIR நகலும் வேண்டும்.You want a written record and a copy of the FIR.

📄 மாதிரிThe template

தமிழ் பதிப்பு
அனுப்புவது
காவல் ஆய்வாளர்,
[காவல் நிலையத்தின் பெயர்],
[நகரம் / மாவட்டம்]

தேதி: [DD/MM/YYYY]

பொருள்: [குற்றம் என்ன என்று சுருக்கமாக] பற்றிய புகார்

மதிப்பிற்குரிய ஐயா/அம்மா,

நான், [உங்கள் முழுப் பெயர்], [தந்தையின் பெயர்] அவர்களின் மகன்/மகள், [உங்கள் முழு முகவரி]-இல் வசிக்கிறேன். பின்வருவது பற்றிப் புகார் அளிக்க விரும்புகிறேன்:

1. சம்பவம் நடந்த தேதி, நேரம் மற்றும் இடம்: [ ... ]
2. என்ன நடந்தது: [ வரிசையாகச் சுருக்கமாக விவரியுங்கள் ]
3. தொடர்புடைய நபர்(கள்), தெரிந்தால்: [ பெயர் / விவரம் / வாகன எண் ]
4. ஏற்பட்ட இழப்பு அல்லது காயம்: [ ... ]
5. சாட்சிகள் இருந்தால்: [ பெயர் மற்றும் தொடர்பு ]
6. நான் இணைக்கும் ஆதாரங்கள்: [ புகைப்படங்கள் / செய்திகள் / ரசீதுகள் ]

என் புகாரைப் பதிவு செய்து, FIR-இன் ஒரு நகலை எனக்குத் தருமாறு கேட்டுக்கொள்கிறேன்.

நன்றி,
இப்படிக்கு,
[கையொப்பம்]
[உங்கள் பெயர்]
[தொலைபேசி எண்]
[முகவரி]
English version
To
The Inspector of Police,
[Police station name],
[City / District]

Date: [DD/MM/YYYY]

Subject: Complaint about [say briefly what the offence is]

Respected Sir/Madam,

I, [your full name], son/daughter of [father's name], residing at [your full address], wish to lodge a complaint about the following:

1. Date, time and place of the incident: [ ... ]
2. What happened: [ describe in short, in order ]
3. Person(s) involved, if known: [ names / description / vehicle number ]
4. Loss or injury caused: [ ... ]
5. Witnesses, if any: [ names and contact ]
6. Evidence I am attaching: [ photos / messages / receipts ]

I request you to register my complaint and give me a copy of the FIR.

Thanking you,
Yours faithfully,
[Signature]
[Your name]
[Phone number]
[Address]

💡 குறிப்புகள்Tips

  • இரண்டு நகல்கள் வைத்திருங்கள்; ஒன்றைப் பெற்றதாகக் காவல்துறையிடம் கையொப்பம்/முத்திரை பெறுங்கள்.Keep two copies; ask the police to stamp one as received.
  • FIR எண்ணையும் ஒரு இலவச நகலையும் எப்போதும் வாங்குங்கள்.Always collect the FIR number and a free copy.
  • பதிவு செய்ய மறுத்தால், அதே புகாரை காவல் கண்காணிப்பாளருக்கு அனுப்புங்கள்.If they refuse to register, send the same complaint to the Superintendent of Police.
